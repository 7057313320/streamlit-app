# 📊 Sales Data Statistical Analysis

A Python project that performs statistical analysis on sales data using **Pandas**, **NumPy**, and **SciPy**. 
It calculates descriptive statistics, category-wise insights, confidence intervals, and hypothesis testing.

## 🚀 Features

- Sales data analysis
- Descriptive statistics (Mean, Median, Mode)
- Variance & Standard Deviation
- Category-wise sales summary
- 95% Confidence Interval
- One-Sample t-Test
- Statistical interpretation of results

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- SciPy

## 📈 Results

- **Mean Units Sold:** 18.8
- **Median Units Sold:** 18.5
- **Mode:** 17
- **95% Confidence Interval:** (17.25, 20.35)
- **P-value:** 0.1206

**Conclusion:** 
The analysis fails to reject the null hypothesis, indicating that the average units sold is not significantly different from 20.
